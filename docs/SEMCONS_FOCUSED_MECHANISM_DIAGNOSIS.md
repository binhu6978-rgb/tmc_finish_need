### 与S03/S06的比较范围

E03/S03的原分区、初始七模型哈希和前10轮实际slot均一致。E03前10轮为2/100个负方向比较，S03为3/490、S06为4/490。后两者的分母是多个结构区域内的slot比较，不能直接按百分比宣称冲突减少多少倍。

还有四项实际定义差异：

1. M2在当轮**全部上传共同交集**计算一个分数，平均仅覆盖Full的19.12%（范围18.57%–29.30%）；S03在各个真实支持区域各自比较。
2. M2的LOO排除当前slot；S03排除同一物理客户端的全部slot，并在证据参考中按客户端去重。E03有165/400轮存在重复客户端。
3. M2得到客户端slot整体权重，再用于其上传的覆盖归一化；S03局部Gate只作用在有比较支持的区域。
4. M2重加权训练后的绝对上传，首轮会改变独立初始化模型的融合；S03保留原生下发融合锚点，只调整真实本地学习增量。后续若所有模型从同一个全局前缀同步，公共下发锚点可一致，但此前轨迹差异仍会累积。

因此，阶段、参考对象、支持范围和首轮锚点均是比较因素。现有结果无法把差异单独归因于九区划分，也没有利用测试Accuracy建立归因。

## 3. 九区内部：有真实抵消，但负向总质量较小

只读工具在每个区域使用与原S07相同的实际本地增量和去重LOO参考，分别累计每个参数张量的点积与双方平方范数，再重建整个区域：

`cos_region = Σ dot_tensor / sqrt(Σ ||delta_tensor||² · Σ ||reference_tensor||²)`。

同一参数张量在同一支持区域中可能包含多个不连续矩形。正式统计先合并这些矩形，再计算张量片段余弦，避免几何切块虚增冲突数。三轮所有点积重建检查通过。

重点使用第2–3轮，避开首轮独立初始化：

|指标|按参数张量×支持区域合并后的结果|
|---|---:|
|区域—slot有效比较|124|
|整体负余弦|0|
|整体非负但内部含负向张量的比较|52/124，41.94%|
|有效张量片段比较|2737|
|负向张量片段|107/2737，3.91%|
|负片段余弦中位数 / 最小值|-0.05258 / -0.28486|
|负点积绝对量 / 正点积总量|0.43665%|
|隐藏负片段的目标更新能量 / 整体目标更新能量|1.98804%|

作为粒度敏感性记录，不合并同张量矩形时是122/3533个负片段、57/124个含隐藏负片段的区域、2.16561%的目标更新能量。这一变化说明，单纯细切块本身就会增加负余弦数量；判断必须同时看贡献质量。

|参数族|有效张量比较|负向比较|负点积绝对量|
|---|---:|---:|---:|
|卷积|1011|12|7.86994e-4|
|分类器|56|4|6.59200e-3|
|BN weight|835|23|1.92889e-6|
|BN bias|835|68|8.02028e-6|

BN占负比较数的91/107，但其负点积只占约0.135%；分类器贡献约89.21%，卷积约10.65%。按触发次数选择新粒度，很容易优先放大低能量BN现象。分类器和卷积中的负向量确实存在，仍需训练侧功能影响观测判断其价值。

**粒度判断：** 值得做单因素粒度对照，但尚不足以确定必须替换正式算法。这是早期三轮、一个种子的更新几何结果；局部负点积和有害更新之间还差一项功能验证。

## 4. 语义证据：存在适应信息，尚未识别干扰与互补

当前Q是不同客户端在各自训练样本上的类别条件`post−pre`概率响应的LOO负余弦平均。共享100个类别坐标保证输出维度可比；输入分布、容量、已有状态和响应幅度仍会影响它。

S04有355个Q>0的区域—客户端记录，**355个均伴随自身共同有效类别的平均真类概率上升**。其平均上升0.2066；Q=0的89个记录平均上升0.4374。S07对应361/361个Q>0记录也全部上升。真类概率变化是原训练探针上的描述量，不能转换为CE变化或跨客户端收益标签。

相关性对比较条件很敏感：

|数据/语义分数|总体Q与自身真类概率增量的Pearson|同轮同区域中心化|再按profile组合中心化|
|---|---:|---:|---:|
|S04真实Q|-0.4124|0.0080|0.5531|
|S07真实Q|-0.4398|-0.1515|0.5476|
|S08同一输入、置换前Q|—|-0.0315|0.3354|
|S08同一输入、置换后Q|-0.4218|-0.0102|-0.0997|

同轮同区域分析保留至少3个客户端的70组、424个记录；进一步控制profile组合只剩15组、54个记录。记录跨区域重复使用客户端，不是独立统计样本，表中不作显著性检验。S08原始/置换分数是在同一输入上比较，避免把不同CUDA进程差异当作负对照效应。

这些结果支持“Q包含自身适应形式/强度的信息”，但其总体负相关很大程度受上下文影响，甚至在打乱后保留。更没有证据把Q>0解释为有害，或把Q=0解释为有益。互补知识同样可能造成响应方向不同。

另一个实现事实是原七模型使用`track_running_stats=False`的BN。测量中的`.eval()`仍使用当前batch统计，因此概率响应也依赖测量batch组成。现有同客户端pre/post复用样本、视图和batch，变化测量是稳定的；跨客户端不同探针的比较仍混合了模型变化与输入/batch上下文。

### 最小缺失观测

需要一项**接收端训练探针上的有符号功能影响**：在另一个确实覆盖同一区域的物理客户端上，固定训练侧样本、类别、视图和batch；比较其实际下发模型与只施加某个上传的该区域增量后的模型，记录逐类CE差值。增量尺度预先使用现有原生聚合系数`n_i/Σn`，所有候选使用同一规则，不按结果选择步长。模型副本、no_grad和完整RNG隔离保证不进入SGD。

同时记录发送端自己的pre/post CE变化，区分“自身适应、对接收端退化”和“双方受益”等情况。探针由接收端原训练分区提供，发送端未在其上执行本地SGD；评估仍属于训练侧机制测量。逐类结果与覆盖约束可以区分具体接收端干扰，尚不能替代全局泛化结论。

本轮没有实施这项新增评分，也没有访问官方测试集来构造语义风险。它是日志目前缺少的最小功能证据。

## 5. 历史冷启动：稀疏参与、区域首次观测、稀少联合事件叠加

三组各100个训练slot覆盖61个物理客户端；history均精确重建为333个客户端—区域键、444次去重有效观测，每键均值1.333次，中位数1次，最大4次。逐轮从原日志重算的`c=n/(n+1)`和保存历史完全一致。

|有效区域—slot比较的类别|数量 / 490|比例|
|---|---:|---:|
|无历史|356|72.65%|
|其中：客户端此前未参与|319|65.10%|
|其中：客户端参与过，但此区域首次有效观测|37|7.55%|
|已有历史|134|27.35%|

319/37是区域—slot计数，不是物理客户端数量。重复slot只累计一次同轮历史，490次有效slot比较成为444次历史事件是预期行为。

S07共有5次D>0且Q>0：4次属于物理客户端首次参加，1次属于已参加客户端首次有效覆盖该区域。S08为4次，均属首次参加；S09为5次，其中4次首次参加、1次区域首次观测。**三组都没有任何联合正风险发生在已有历史的134个比较上。**

因此全中性不是历史没有积累，也不是只有首轮初始化保护，而是联合事件稀少且与历史成熟区域没有重合。无历史占72.65%显示当前设计早期很保守；E03后期冲突增多又表明早期不足以判定其长期无效。本轮保持该规则。

## 6. 联合乘积与唯一优先方案

当前乘积`D×Q×c`可以保留为固定候选对照，现有证据尚不支持将其视为已经验证的完整机制。D本身稀少，Q通常只有约0.006，c又对首次观测给0；这种乘积同时承担事件筛选和幅度收缩。更关键的是Q尚未校准为干扰风险。即使提高触发率，也无法自动弥补这一语义缺口。

**唯一优先方案：先用固定接收端训练探针的有符号CE影响校准语义证据；若它能区分接收端退化与互补，再审查以这种功能影响证据替代当前“响应分歧Q”的最小修正。** 原结构覆盖、方向参考、历史和归一化先保持不变，避免同时改变多个因素。上节只读观测是此方案的前提，尚未设定新Gate公式或默认阈值，更未写入训练算法。

科学理由是：本轮已经确认局部负方向存在，但量较小；还确认当前Q对应自身适应而非已测得的他人损害。优先建立“功能证据→接收端影响”的联系，比直接把更多局部负余弦送入乘积更能检验SemConsFL的主线。

|判断|证据状态|
|---|---|
|早期冲突少、E03后期频率更高|已由400轮日志确认|
|九区拼接会掩盖部分局部负向|已由真实张量分解确认|
|这些局部负向必然有害或应被抑制|尚未确认，缺接收端功能影响|
|Q包含适应信息|描述性证据支持，受上下文影响|
|Q能区分干扰和互补|现有观测不足|
|历史正确积累，联合事件均处于冷启动|已逐轮重建确认|
|现有机制400轮都不会激活|尚未确认，早期预检不能外推|
|应立即实施新聚合或增加Gate强度|现有证据不支持|
