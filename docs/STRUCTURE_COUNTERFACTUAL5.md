# 成熟阶段结构约束聚合：五批离线反事实

**结论：A4正确限制了干预范围，也产生了非零聚合变化；但本次没有显示优于原聚合、M2或M3的平均训练探针CE。A4相对A3的微小原始优势，在匹配更新尺度后反转。现有证据不支持优先启动A4的400轮实验。**

## 数据与固定评价

复用本地E03第400轮 `latest.pt`、此前5批完整分区真实上传/下发和已物化的100个物理客户端训练探针。没有生成新的SGD更新，没有加载原始图像或官方测试集，没有使用 `best` checkpoint。5批均从同一个最终Full锚点独立生成反事实，互不传递聚合结果。

每个Full模型在完全相同的100个客户端探针上评价，每客户端固定16类×2张、一个32张batch，保留原BN无运行统计的评估方式。主指标为客户端等权CE，再对5批等权平均；每个方法每批均使用同一100客户端面板，共3,200张固定训练探针图像。另按原4:3:3设备容量分组（cid0–39 / 40–69 / 70–99）以及当批参与身份报告。它们是训练侧诊断，不是完整训练集损失或独立验证集损失。

100个相同物理客户端跨批重复出现，五批共享同一个成熟模型。下述500个“客户端×批次”观察不是500次独立重复；不据此报告显著性或正式Full Accuracy优势。保留预定 `1e-6` CE中性容差，固定batch重复前向的最大差为0。

## 五种方法

- **A0**：直接调用原 `Aggregation_AdaptiveFL`。
- **A1**：直接调用现有 `MethodHooks(method='m2', conflict_lambda=4)`。
- **A2**：直接调用现有M3，shared=1、remainder=0.98。shared仍是七档真实公共前缀，remainder是补集，不是原论文的两个模型重组分区。
- **A4**：直接调用现有 `ScopeHooks(method='s03', conflict_lambda=4)`，使用9个真实覆盖区域与物理客户端LOO方向证据；不读取Q决定权重。
- **A3**：仅为本次离线控制，复用A4实际计算出的同一份区域方向风险。先在每区域内对同一物理客户端的有效重复slot风险取均值，再按区域参数量加权平均有效区域风险（有效的零风险也计入分母，缺失比较不计入）。每个物理客户端取得一个 `g=exp(-4*risk)`，作用到它覆盖的全部区域。

A3和A4均从相同原生覆盖聚合结果出发，只改变实际 `trained - dispatched` 学习增量的混合；每个坐标按门控后的覆盖权重归一化，保留原生下发融合锚点。重复slot的上传和样本权重不合并；没有覆盖的参数不变。只由一个物理客户端提供的区域，即使A3整体Gate非中性，也因共同因子抵消而保持原聚合。

**归因限制：** A3不仅扩大了干预范围，还把区域风险汇总成一个平均值，使局部强风险被稀释；对重复slot也进行风险池化，而A4保留各slot的方向风险。本次真实数据有7个“区域×重复客户端”组合的slot风险不相等。因此A3/A4不是只切换作用掩码的严格单因素对照，不能把所有差异归因于范围。

M2另有全上传交集、slot级LOO及客户端整体重权等差别，与A3不等价；本次锚点已成熟同步，没有首轮独立初始化融合混入。

CE越低越好；“改善”统一定义为 `CE(A0) - CE(method)`，正值有利。L2和参数比例均为5批平均；参数变化是相对A0的实际FP32差异，不表示同等比例的有效学习。

## 干预范围和归一化抵消

254次有效区域-slot方向比较中51次风险为正。A4在25个区域-批次触发Gate，22个产生实际聚合变化；相对A0差异L2平均0.00189570，按各批原学习增量归一化后平均约1.02%。所以它确实干预，但“43.79%坐标变化”不能被解读为43.79%的更新强度变化。

| 批次 | 负方向区域 | A4实际改变区域 | A4共同Gate抵消区域 |
|---|---|---|---|
| 1 | 3、5、6、7 | 3、6 | 5、7 |
| 2 | 0、3、4、5、6、7、8 | 0、3、4、5、6、7 | 8 |
| 3 | 0、3、4、6 | 0、3、4、6 | 无 |
| 4 | 0、1、2、3、6、7 | 0、1、2、3、6、7 | 无 |
| 5 | 0、1、3、6 | 0、1、3、6 | 无 |

前三处抵消区域都只有两个不同物理客户端覆盖，其对称LOO余弦产生相同Gate。共同乘子在归一化中抵消，原实现精确返回A0；这不是数值错误，也没有为制造非零干预修改规则。

A3在43个区域-批次、170个区域-slot使用非中性Gate，其中119个slot在对应区域并无正方向风险；40个区域实际改变。例：第4批Full-only区域8没有局部负方向证据，A4保持原聚合，A3因其他区域风险外推而改变了它。A3另有3个单物理客户端区域因共同Gate抵消。全部45个区域-批次的覆盖、冲突、Gate、实际变化坐标数和L2见 `regions.csv`，详细方向风险与整体风险见 `diagnostics.json`。

## 是否只是更新幅度变化

在评价前固定两个无搜索对照：分别把A1–A4完整学习增量重缩放到同批A0的L2；以及只把A0缩放到A4的L2。系数完全由权重计算，不利用CE选择，不改变任何正式方法。

| 尺度对照 | Full探针CE | 相对A0改善 |
|---|---:|---:|
| A3匹配A0更新L2 | 0.334075265 | +0.000011673 |
| A4匹配A0更新L2 | 0.334141661 | −0.000054723 |
| 只将A0缩放到A4的L2 | 0.334115888 | −0.000028951 |
| A2匹配A0更新L2 | 0.334116324 | −0.000029387 |

原始A3/A0更新L2比平均1.011014，A4为1.001170。两者匹配到同一A0尺度后，A4反而比A3恶化0.00006640，原始的相对优势不再成立，不能排除尺度差异的解释。

Gate小于1并不保证总更新缩小：覆盖归一化会重新分配相对贡献，本次A3、A4的总L2均略有增加。全局L2匹配只控制总体尺度，不能同时固定各层、各区域的幅度；再加上A3的风险汇总差异，本次无法单独估计“只限制作用范围”的因果收益。

A4与A0更新的余弦平均0.999938，仍有实际方向/区域混合变化：在A0尺度下A4仍比A0差，而把A0简单缩放到A4尺度的CE也优于原始A4。这说明A4不只是一个全局乘子，但额外的方向变化在该面板上未带来收益。不能把这份负结果改写成已证明“干预范围更正确所以学习更好”。M3本次原始收益在匹配L2后也消失，不能将其离线优势外推为正式训练优势。

## 明确回答

1. **A4是否生效？是。** 聚合边界及归一化处理正确，22个区域-批次实际改变，但强度有限，生效不等于收益。
2. **是否比A3更有效？原尺度略好，证据不稳。** 4/5批更好，但平均差极小，同尺度比较反转；还有风险汇总/重复slot池化差异。
3. **能否优于M2和M3？本次没有。** 平均落后M2，且五批全部落后M3。
4. **能否排除纯尺度解释？不能为A4相对A3的优势排除。** A4确有方向变化，但尺度控制后未保留优势。
5. **是否值得优先进入400轮？当前不建议。** 这一成熟状态上的离线结果没有给出优于已有方法的正向依据；不追加模块、参数或试验来修饰结果。

这不是对所有结构约束聚合的否定，也不能证明任何方法的最终Full Accuracy或test-oracle peak。该锚点来自M2历史轨迹，一次聚合反事实不能替代各方法自然训练400轮的结果。它回答的是当前实现、当前固定成熟状态及五批真实更新上的有限问题。本项到此结束，等待审核。
