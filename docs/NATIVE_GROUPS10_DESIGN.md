## 几何与记号

仅复用`semcons_scope.build_regions`/`slices`几何函数，根据真实七模型state形状将Full精确分成9个结构覆盖区域。
不调用S03方向、Q或任何语义测量函数。区域按支持该区域的模型档位集合定义，包含卷积、BN和分类器，
不改变原prefix映射；G04的共同区域是**静态七模型全部共同覆盖区域**，不是当轮上传的最小交集。

对区域r，本轮实际覆盖它的槽位为I_r；槽位i上传U_i、下发D_i、样本量n_i、物理身份c_i、模型档位p_i。
原生结果B先完整调用原AdaptiveFL覆盖归一化聚合。没有槽位覆盖的区域始终保持原Full W，所有新分支跳过该区域。
独立上传和本地SGD均保留，同一物理客户端重复出现时不合并训练。

## G01/G02/G03/G04/G05/G06：权重来源

G01按p_i分组。每组先按n_i平均上传，再对实际出现的模型组等权平均：
`sum_g [(sum_{i in g} n_i U_i / sum_{i in g}n_i) / K_r]`。
服务器等效槽位权重为 `n_i / (K_r * sum_{j in same profile}n_j)`。
实现将这些权重乘一个共同正比例因子，以保持Native总质量量级，不改变覆盖归一化结果。
若有效权重与Native成共同倍数，直接保留Native，避免将中性舍入误差包装成机制。

G02按物理客户端分组，仅合并**覆盖当前区域**的上传。重复客户端的数据量必须相同。
先平均该物理客户端的k_{c,r}个上传，再按其原数据量n_c聚合一次，等效槽位权重n_c/k_{c,r}。
某个重复客户端只有一个slot覆盖某区域时，该区域不人为计入其他不覆盖的slot。

G03按原物理能力ID `[0,40)`、`[40,70)`、`[70,100)`分组：组内保持Native样本-slot权重，组间等权。
该组不额外进行G02的去重；目的是单独研究能力层级均衡。高能力客户端训练小模型仍属于高能力层，
因此不能用模型档位代替物理能力。

G04只在静态七模型共同区域应用G01；G05只在其补集应用G01。
对完全相同上传和锚点，G04在共同区等于G01、区外等于Native；G05反之。

G06对每个坐标的实际覆盖slot等权，不使用n_i，不改变重复slot或数据采样。

## G07：累计去重覆盖机会补偿

只保存9个非负整数：
`C_r(t) = C_r(t-1) + number_of_distinct_physical_clients_covering_r_at_t`。
同一物理客户端同轮在同一区域只计一次，不跨区域合并；第1轮虽不干预，仍计入真实机会。
不保存历史梯度、方向、Q、单客户端历史或可靠性状态。

使用**全部9个区域累计次数的等权算术均值** `Cbar(t)=sum_r C_r(t)/9` 作归一化参考。
对于本轮有上传的区域：`g_r=clip(sqrt(Cbar/C_r),0.8,1.2)`。
本轮收到上传则C_r>=1，不需要伪计数；无上传区域即使累计为0也不计算增量或凭空更新。
未要求裁剪后增益均值为1；任何总体强度差异由G08单独检验。

从第2轮起原生同步保证所有实际下发等于W对应prefix，代码逐张量检查这一条件。
因此以Native锚定学习变化 `L_r = B_r-W_r` 构造 `W_r + g_r L_r`。
该变化保留原聚合的浮点舍入含义，不重写下发融合；增益为1时直接返回Native。
首轮独立初始化融合完整保留Native。

## G09：独立物理客户端块的区域信号收缩

只读实际SGD变化 `d_i=(U_i-D_i)_r`，使用float64计算统计量。
将同一物理客户端覆盖该区域的slot汇成一个统计块：

`M_c=sum_{i:c_i=c}n_i`，`d_c=sum_i n_i d_i/M_c`，`a_c=M_c/sum_c M_c`。

这里保留Native的总slot质量：`mu=sum_c a_c d_c`仍等于原生slot样本加权学习均值，
没有在G09偷偷叠加G02去重聚合。重复slot不能被当成新增的独立客户端观测。

有K>=2个物理客户端时：

```
A2 = sum_c a_c^2
E  = ||mu||^2
V  = sum_c a_c ||d_c-mu||^2 / (1-A2)
N  = A2 * V
S  = max(E-N, 0)
g  = S/(S+N)
```

V是在独立、同方差客户端块近似下的加权无偏离散能量估计，N估计均值噪声能量，S是非负信号能量估计。
采用固定非负经验Wiener收缩；无新可调阈值或系数。
若S=N=0则g=1；只有一个不同物理客户端则直接g=1，不估计跨客户端噪声。
多客户端完全一致时V=0、g=1；均值较弱而离散较大时g可为0。
同G07，仅缩放Native相对W的区域学习变化；不改变Native基础权重或未覆盖参数。

**科学限制：**Non-IID客户端并非真实同分布噪声，分歧可能包含互补信息。
因此N是待检验的收缩依据，不能预先称其为真实有害更新或无偏可靠性。
没有方向余弦、客户端冲突评分、语义信号、历史可靠性或新本地损失。

## G08/G10：同输入全局尺度控制

在本组自己的相同上传、相同W及相同累计计数上，虚拟计算G07或G09结果V，不将其分区域用于最终模型。
设 `s=||V-W||/||B-W||`，最终只对所有实际覆盖参数统一返回 `W+s(B-W)`。
若Native增量为0，虚拟区域增量也应为0，此时保持Native；非零虚拟量无法由零方向缩放得到时明确报错，
不创造额外方向。未覆盖区域仍直接保留Native/W。

日志记录虚拟L2、实际L2、s、绝对与相对匹配误差；浮点32模型存储允许正常舍入误差。
控制组与区域组训练后会分叉，不能宣称两条完整训练轨迹的每轮L2相同；
匹配指每个控制组在**自身同输入反事实**上的尺度匹配。
