## 数据与BN评价方式先冻结

建议主probe为**原始50000个训练样本中的固定2048个**。按SHA256("FD-utility-probe-v1/"+原始索引)最小的2048项选取，再按原始索引递增排序；不使用标签、风险、准确率或测试峰值挑样本。分析产物`proposed_probe_indices.json`已冻结索引、原始train文件SHA256、分区哈希及各客户端probe重叠数量。本阶段没有执行任何probe前向。

所有50000个训练样本仍属于原始客户端并参与原训练；probe不是新验证划分，也不是独立泛化数据。它只能说明固定训练probe上的更新效用。不得用训练probe改善宣称论文泛化收益，不得使用官方测试集反复筛选候选。正式官方测试协议保留；若需新增独立数据，另行解释必要性并请求授权。

输入保持原ToTensor/Normalize干净变换，Full eval mode、batch size=128、16个固定batch、相同顺序/成员。B/A功能测量仍用原batch50，二者不能混用。ResNet BN不跟踪运行统计，eval仍依赖当前batch，因此每个反事实必须使用完全相同批组成。禁止通过删probe中某客户端样本来重新分batch；若报告其余客户端probe子组损失，只能在相同完整batch的逐样本loss上做后置掩码，并明确BN上下文仍共享。

反事实评价在采集训练结束后单独进行，加载同一Full架构，每个候选恢复状态/模式/buffer；固定确定性诊断后端用于**只读评价**并记录，不能带入原训练。先重复无变化baseline并检查逐batch输出与CE可复现，记录数值误差。局部训练不强行改确定性设置，也不假定新上传逐位等于旧上传。

## 同一批上传的五类研究对照

令θ为聚合前Full，W_i为第i槽位上传，P_i为原profile的prefix映射，n_i为其原样本数。定义δ_i=W_i−P_i(θ)。坐标覆盖分母为D_j=Σ_i n_i·1(i覆盖j)，未覆盖坐标保持θ。

1. **原生AdaptiveFL**：使用原始聚合函数生成golden结果。数学上Δ0_j=Σ_i n_i·P_i(δ_i)_j / D_j。
2. **正式Gate**：Δg_j=Σ_i n_i·γ_i·P_i(δ_i)_j / D_j，始终固定原D；A2/A3分别按各自冻结定义计算，报告研究对象清楚。本最小采集以A3轨迹和A3正式Gate为主，另一个校准候选仅作为固定上传shadow。
3. **同幅度普通缩步**：α=||Δg||₂/||Δ0||₂，θ+αΔ0。主匹配量为整个Full参数更新L2，另报Full-only/部分共享/全部共享区域的范数及方向cosine；不假装全局范数相等就能同时匹配各区域。若α>1，标为放大而非缩步，不能偷偷clip后声称匹配；若Δ0=0且Δg非零，则标记无可匹配对照。
4. **同profile风险置换**：固定20次预登记分析置换，不搜索最优种子。每轮每profile先按物理客户端组成组；同一(client,profile)的多个槽位作为按slot排序的风险向量整体置换，且仅在相同重复次数的组之间置换，防止拆散重复客户端或改变向量长度。少于2组或所有风险相同时标为退化，不制造随机对照。跨profile的同一物理客户端仍作为相关组处理，不能把每profile观测当独立受试者。置换后原覆盖分母不变，主要效用比较再将置换合成更新匹配到||Δg||₂，另记录匹配前范数和缩放系数。
5. **客户端组边际效用**：对同一物理client的所有槽位（包括跨profile）同时处理；采用下面两个明确不同的定义，不将其混合。

正式代码在全γ=1时调用原绝对参数聚合，而非门控delta路径；float32算术顺序可能略有不同。保存原golden结果，并增加“delta公式、γ全1”的中性算术bridge检查。所有诊断delta反事实使用同一精度/顺序，比较与golden的参数和CE误差；必要时另做FP64服务器计算后一次cast回float32作为数值诊断。bridge差异应报告，不得冒充语义效应，也不得改正式训练聚合实现。

## 两种边际更新效用，符号与分组

令S_c为同一物理客户端在该轮的全部槽位，L为上述冻结probe的Full平均交叉熵。

**固定原覆盖分母，只消除分子贡献：**

Δ(−c,fixed)_j=Σ_{i不属于S_c} n_i·P_i(δ_i)_j / D_j。

原D_j保留被删除槽位的覆盖权重。这衡量该客户端原加性更新贡献；并非重新组织联邦参与人群。

**真正移除客户端并重算分母：**

D(−c)_j=Σ_{i不属于S_c} n_i·1(i覆盖j)，Δ(−c,renorm)_j按D(−c)归一化；无剩余覆盖则该坐标恢复θ。

这同时改变其他客户端归一化权重，回答的是移除参与者后的组合效用。不能将它解释成原分母下同一加性贡献。

两种定义均预登记：U_c=L(θ+Δ−c)−L(θ+Δ0)。U_c>0表示删除后loss变高，原贡献有益；U_c<0表示删除后loss变低，原贡献有害。若用“有害性分数”，定义H_c=−U_c，明确正负。门控组合改善用ΔL_gate=L(θ+Δg)−L(θ+Δ0)，负值才是该probe上有益。

主组级风险采用原样本权重均值R_c=Σ_{i∈S_c}n_i·risk_i/Σ_{i∈S_c}n_i，预登记最大risk为次要描述，同时报告重复数和profile集合；不能在见效用后选更有利的组风险定义。风险-效用比较按轮次/profile/物理client相关结构进行，控制n及上传/组贡献范数。一个批次只有9个客户端组，不报告基于10个槽位的伪独立显著性，也不以3个历史正例估计可靠ROC/FPR。

## 前向工作量与停止界限

一个2048-sample probe对应16个Full batch。每个固定上传批次，若20次置换均有效，基础/门控/普通缩步/置换约23个模型，加2×G个客户端边际模型，再加中性bridge及重复baseline；G=9时约43–45次Full probe评价，即688–720个Full forward batch。实际退化置换可能减少唯一模型数量。此前日志未独立计时Full前向，不能据此给出精确评价分钟数；授权后先用固定少量前向计时并报告预算，不自动扩充规模。

若扩至100个上传快照，相应约68800–72000个Full batch，可能成为主要额外成本。先完成单批可行性，不直接启动全轨迹评价。

必须先验证：保存上传可重算factual聚合；全γ=1与原函数数值bridge在可解释范围；冻结BN批评价稳定；缩步确实匹配范数；置换有足够非退化组；client93重复两个槽位共同删除；两种分母定义正确；Memory/分区/原始checkpoint均未被写回。

只有在风险与有害性标签存在稳定关系，且门控相对匹配范数缩步与置换对照确有优势后，才有理由申请更多预定状态/种子的确认和正式长程实验。单批训练probe改善不证明独立泛化，也不能将shadow活跃率当性能结果。
