# E03方向证据约束与负投影保护：固定设计

本次只比较C1、C2两个新候选，各自从原seed1独立七档初始化训练400轮。服务器hh环境、物理GPU0、C1完成后再启动C2；不续接E03最终状态，不重跑B00/E03/N08，不使用M3、Q或Memory。

## 原M2实际计算

对所有当前上传的共同交集E，取实际SGD增量 `d_i=(U_i-S_i)_E`，其中S_i是对应slot真实下发，U_i是训练后上传。原M2使用按样本数加权、排除自身slot的参考 `r_i=sum_{j!=i} n_j*d_j / sum_{j!=i} n_j`。重复物理客户端的其他slot仍在参考内，这是原M2语义，本次不改成物理客户端LOO。

原余弦 `c_i=cos(d_i,r_i)` 与风险 `max(0,-c_i)`，λ固定4。定义 `g_i=exp(-4*max(0,-c_i))`，无有效方向的slot取1。原源码为了稳定而将logit减去最大值，得到相对权重w_i；w_i与g_i只差共同因子，在原生覆盖归一化中相消。

M2把w_i乘到整个上传的样本权重，然后调用原 `Aggregation_AdaptiveFL`，并不只处理E，也不只重权SGD增量。因此它同时重权下发状态融合和SGD增量。交集外有多slot共同覆盖的区域也会被改变；仅单slot覆盖的坐标，其权重因覆盖归一化自然抵消，不应笼统声称独占参数也被直接压低。

## C1：严格作用域控制

同时调用原M2和原聚合。E内逐坐标使用原M2结果，E外使用原AdaptiveFL结果。全部余弦、风险和权重直接由原 `MethodHooks(method='m2')` 计算，没有复制一套评分规则。E取当前所有上传实际形状的逐键公共前缀，不是固定七模型最小前缀，也不是S03九区域。

这是相对E03的作用域单因素修改，包括E内原M2的下发融合规则和首轮独立初始化融合都保留。

## C2：只衰减负投影

沿用完全相同的E、d_i、r_i和g_i。以单位参考q_i=r_i/||r_i||计算：

`p_i = min(dot(d_i,q_i),0)*q_i`

`z_i = d_i-p_i`

`d'_i = z_i+g_i*p_i`

p_i是负投影，z_i是剩余分量；对负余弦样本，z_i与参考正交。非负或无有效方向样本p_i=0。正交不意味着语义有益，只是避免未经证据支持地连带缩小它。

取原生样本比例 `alpha_i=n_i/sum n`，M2归一化比例 `beta_i=n_i*g_i/sum(n*g)`。E内固定：

`C1_E = sum beta_i*S_i + sum beta_i*d_i`

`C2_E = sum beta_i*S_i + sum alpha_i*(z_i+g_i*p_i)`

实现用 `C1_E + sum alpha_i*d'_i - sum beta_i*d_i`，保留原M2的融合项。E外仍严格使用原AdaptiveFL，覆盖不足和无覆盖处理不变。无负冲突时精确返回原聚合，不进行近中性重写。

学习项使用原生覆盖分母，不再按投影门控质量重归一化；否则会重新放大受保护分量，或使共同门控完全抵消。g_i必须用原始未平移logit的指数，不能直接使用减max后的w_i：后者的公共因子只在重归一化中无关，不能被当作非重归一化的衰减尺度。这个选择固定、无新超参数。

两种候选在E内保持相同的M2下发融合；C2对学习项的固定分母改变是分量保护设计的一部分，不应把C2/C1差异说成仅修改一个掩码。第1轮仍存在原独立模型融合，评分永远只用真实U_i-S_i，不把初始化差异当成SGD更新。第2轮起各模型公共下发前缀对齐，数学上融合锚点相同。

## 稳定性、诊断和约束

投影在float64中使用单位参考计算，避免除以很小的参考平方范数；有效方向阈值复用M2的1e-12。g_i在[exp(-4),1]，没有可调阈值、裁剪或新损失。由于各slot参考不同，不声称所有剩余分量共同位于同一个正交子空间。

C1保留原M2共同权重归一化可能抵消的性质，这是保持原权重公式的必然结果。C2在负投影上保留共同衰减，可避免该种抵消；但若真实更新恰好对消，仍可能没有净聚合变化，不人为强制非零。

每轮保留原评分/权重、冲突slot、交集范围、相对同输入E03及原聚合的实际参数差异与L2、总更新范数比及沿E03的有效步长。C2另记各slot负投影、剩余分量、调整量及相对E03恢复的剩余聚合变化。首轮单独记录M2融合相对原融合的位移。

Full-only原评估、七档同步、RNG隔离、原分区、100客户端/10slots/5 local epochs/batch50/SGD/衰减等全部保留。旧M2、原聚合函数及原本地SGD源码不变。新增入口只适配数据根目录并调用原训练循环。

正式结果只能在各400轮真实完成后报告。所有最高测试值标为test-oracle peak；最终、Last20、Last50、CE和曲线直接取真实日志。历史B00/E03/N08不重训；新实验与历史GPU0 hh环境一致但CUDA过程仍有原本非确定性，不能据同seed宣称bitwise一致或独立统计显著。若两候选不优于E03，不追加调参。
