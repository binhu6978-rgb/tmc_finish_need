## 3. 中性原因、归一化抵消和历史

**语义风险没有长期为零的迹象。** 这10轮中，各组约80%的有效区域—客户端语义分数非零。但分数通常较小，和稀少的方向负余弦取乘积后，联合风险进一步缩小。S06最强抑制也只有约0.1168%。

**两客户端对称抵消在真实数据上存在。** 每组有10个恰好由两个不同物理客户端覆盖的区域—轮次。S04其中3个区域Gate非中性，但3个均为共同Gate、全部被归一化精确抵消，实际改变坐标为0。占S04全部70个活跃Gate区域的3/70=4.2857%，占其双客户端活跃区域的100%；其余67个活跃区域确实改变参数。其他组的双客户端区域没有活跃Gate，抵消率分母为0，应记为“不适用”，不能写成已验证不会抵消。

数学原因：两个客户端的类别比较使用同一交集，`cos(a,b)=cos(b,a)`，故语义风险相同。两边只有一个上传slot时，方向风险也对称。共同系数`g`满足`Σn g d / Σn g = Σn d / Σn`。重复slot、不同历史置信度可能打破部分联合Gate对称性，但不能假定必然如此。没有可归因的非对称证据时，保持中性有合理性，不能随机打破对称来制造干预。

**历史正常积累，但尚未与冲突事件重合。** S07/S08/S09均累计444次去重后的客户端—区域—轮次有效观测。置信度均值从首轮0增加到第10轮0.321895，最大值0.75；它不是单调逐轮上升，因为每轮参与客户端不同。三组第10轮的历史计数和置信度统计一致。

S07的5次联合正风险出现在第1轮3次、第2轮1次、第9轮1次；5次均为该物理客户端/区域首次有效比较，`n=0,c=0`。S08的4次、S09的5次联合正风险也全部对应零历史置信度。不是所有冲突都只发生在第1轮，也不是历史状态没有保存；是目前“同一客户端/区域既有历史且当前发生联合冲突”的交集为空。

## 4. S08负对照和S07/S09真实输入重放

S08置换了444个区域—客户端分数位置，其中385个数值实际改变（86.7117%），涉及61个不同物理客户端、91个按轮去重的客户端—轮次。59个数值未变不应算成有效语义破坏，其中双客户端区域的20个分数全部未变：两侧原分数对称，交换后仍相同。

每个区域置换前后的分数多重集合保持一致；S07/S08的实际参与slot与有效类别集合一致。负对照没有通过改变类别有效性或参与者集合产生额外效果。**385次分数变化仍未产生任何Gate变化或参数修改**，因为联合冲突与正历史置信度没有重合。因此负对照的置换实现有效，但尚不足以比较真实语义的训练价值。

在S07的每一轮，复制**聚合前**的真实观察、历史、实际下发快照和训练后上传，调用原S09公式，随后丢弃额外聚合结果。额外计算不进入下一轮，不保存为正式checkpoint，且RNG隔离。10次重放的Gate、历史完全一致，S07/S09结果差异L2均为0；两条独立真实训练也均全中性。

这验证了真实中性输入下的退化一致性，**没有验证非中性真实输入上的分母效果**。构造单测能显示非中性时两公式有差别，但不能替代本次未获得的真实激活证据。若未来Gate激活，同输入下S09学习增量应为S07增量乘以`Σng/Σn`；本次该比例始终为1。

## 6. 最小下一步建议，尚未实施

现有证据不足以让整套五批训练回答S06/S07、S07/S08、S07/S09的科学问题，建议继续暂缓正式队列。现阶段没有理由提高Gate系数、降低语义阈值、取消历史保护，或为了非零裁剪/门控而改公式。

1. 在既有九个结构支持区域内，额外分解参数张量/层的方向统计，检查跨层拼接是否掩盖局部负向更新。先仅观察，不改变聚合。若证实存在这种抵消，最小算法候选是把方向比较细化为“参数张量×原支持单元”，仍仅干预有多个不同客户端支持的重叠位置，保留原锚点和覆盖归一化。该候选需要另行审查，未加入代码。
2. 使用预先指定的既有baseline最终状态，而非test-oracle最佳状态，另做成熟阶段的只读/独立短程观测，区分“训练早期冲突少”和“机制长期不触发”。历史应由真实观测积累，不能伪造非零计数。这将是另一项需授权的预检，本次没有执行。

S08不需要为了提高“改变数”而重写置换；双客户端对称区域应明确报告不可识别性。也不建议在没有独立证据时强行打破归一化的共同Gate抵消。以上建议不依据官方测试集准确率，本报告不提供精度优劣或语义带来收益的结论。
