# A07 / Semantic-A07 V2：500轮机制证据与最终判断

**结论：保留冻结A07作为有效性能基础；本次冻结V2未获得成为最终改进算法的证据。** 两组真实完成500轮，V2的峰值、末轮、末20/50轮均值及最终CE均落后A07。评分有部分汇总关联，但缺少稳定的增量解释；同输入语义融合效用接近零。完成本次固定预算后停止，不追加实验或更改公式。

## 2. 机制采样和有效样本

采样轮次在训练前固定：1、2、8–24、242–258、484–500，共53轮/轨迹，覆盖早、中、晚期。实际上传及真实dispatch仅在内存用于反事实计算。每条轨迹保存1326条来源—区域—接收者配对，以及1908条Full探针评价（53轮×6个物理接收者×6种同输入模型）。全部中性、负效用和缺失记录保留。

接收者按预先冻结的物理身份hash分为主分析confirmation与辅助development。主共同类别分析为395条相关响应，折叠为**74个不同的(source tier, round)评分单元、29个轮次**；低/中/高来源分别18/28/28。辅助共同类别分析为66个单元；两cohort合并的全部类别有效评分仅76个不同单元，不能把接收者、区域、两条相关轨迹重复计为独立FL实验。

独立物理接收者排除相同来源客户端。固定probe与语义评分图像索引分开；相同注入的前后评价使用相同输入、次序、batch50及BN batch组成。为保留原完整训练协议，probe仍来自SGD训练集，存在训练侧评价偏差。官方测试集仅用于每轮Full性能，不参与U、Memory、配对选择或效用标签。

分阶段结果更弱：V2早/中/晚期共同类别相关分别为−0.3571、0.0072、0.0435，对应15/36/23个单元。U与轮次相关为−0.5979，存在明显训练阶段混杂。固定ridge=1控制更新L2、方向、能力、profile、样本质量、区域规模、标签分布及基线CE后，加入D/M/U的留轮MSE相对简单控制反而增加2.92%；按接收者分组仅减少0.624%；留阶段MSE增加129.05%。Anchor-only在个别划分上有增量，但跨轨迹和分组不能稳定复现。

两种类别口径的差异具有可核验的组成解释：共同类别平均只占固定probe样本的19.91%。对同一注入，`全类效用=f×共同类效用+(1−f)×非共同类效用`，最大数值残差1.39e−17。V2共同类单元平均效用0.01816，但有0.64687的大正值，已完整保留；非共同类平均0.00104、与U相关0.4194。全部类别混合了不同支持范围、方差及训练阶段，不能直接用其相关性替代共同类结果。预先固定U分箱的单元数61/7/6，误差范围宽，共同类别均值也未呈稳定单调关系。

## 7. 科研决策

1. **语义评分关联：部分支持，缺少稳定增量。** 全类别汇总存在正相关；共同类、分阶段、置换及分组预测结果不足以确认可靠跨客户端效用信息。
2. **同输入聚合改进：未获支持。** 完整V2均值接近零，对Memory消融、置换和L2控制的优势区间均包含零。
3. **完整V2性能：本次为负结果。** Peak下降0.78个百分点，Last20下降0.63个百分点，CE增加0.02405。
4. **论文资格：保留A07；冻结V2作为真实机制探索和负结果。** 当前数据不足以将四阶段语义融合写成已验证优于A07的最终算法，也不足以声称双Memory具有各自独立收益。保留原始证据和代码，不追加种子、强度搜索或新机制。
